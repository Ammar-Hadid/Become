## Delivered experience

`/reviews` opens current/previous Week, Month, Season and Year readings and paginated saved review history. Period navigation reaches older readings without requiring a pre-existing review row. Reviews connect recorded focused time, outputs, receipts, intentions, choices and user reflection. Source dialogs explain the complete qualified aggregate, with canonical drill-through and bounded pages. Defining moments use deterministic recent records and optional user selections; no importance score is inferred.

Season reviews receive the richest treatment. The finale at `/direction/seasons/{year}/{quarter}/finale` unfolds through four manually advanced movements:

1. The Season's saved identity and recoverable original direction, with approved artwork and honest quote attribution.
2. A visual time reading and one selectable dated memory at a time.
3. Selected domain outcomes and intentions, with qualifications and fuller detail available deliberately.
4. The user's preserved closing words and carry/leave material, followed by the existing next-Season opening.

Only one movement is visible in the ordinary ceremony. The numbered 01–04 controls select the actual ceremony scene, including direct jumps and revisits; there is no alternate ceremony reading view. The full review remains a separate page. Reduced motion uses these same scenes without animation. Native disclosures, selected domain/moment views and authenticated COTS/Content imagery retain the information while reducing simultaneous visual load. The duplicate top Not now is removed; the sticky footer retains the exit. Screen one’s composition is preserved. No forced wait, confetti, generic dashboard slideshow or fake character farewell. Motion uses the existing shared timing/easing: a moving selection guide, directional scene carry, a local portrait settle, and bounded memory/carry-word recomposition. The foreground scene carries in the selected forward/back direction while the sticky numbered navigation and footer remain anchors. Heading scroll clearance keeps titles below the numbered row on phones; evidence dialogs use the document overlay layer so scene transforms cannot trap them. Reduced motion removes these effects from the same scene structure. No dependency or typography-token change was required.

Fresh finale entry is an uncaptured preview. The client submits the preview facts fingerprint, review version and selected edition; changes to writing alone are detected before first capture. The first explicit Continue or numbered scene change captures its presentation, or binds the exact previously saved edition displayed by the preview. A link offers the full review first so the user can write/finalize before beginning. Existing captured presentations resume their saved meaning. The final beat is authored neutral interface copy plus the user's own words; no empty AI placeholder.

Carry-forward material is a reviewable suggestion in the existing opening. Selecting and applying words is explicit, existing answers are preserved until that action, and canonical goals are never duplicated. Unapplied suggestion edits, pending review writing and uncertain opening saves have user/period/edition-scoped local recovery. Successful finalization/amendment navigates to its exact saved edition.

## Calendar, participation and nonblocking behavior

- Seasons are fixed calendar quarters in Europe/Amsterdam. Weeks start Monday. Timestamp windows are half-open; `startOn` and `endOn` are inclusive display dates. SQL converts date-owned domain records at Amsterdam boundaries.
- Finalization requires an ended calendar period. Open periods support saved writing and explicitly provisional readings. Equal elapsed comparisons apply to partial periods; if the previous period is shorter, comparison is unavailable. Completed periods compare full calendar windows with differing lengths labeled.
- Participation requires actual qualified records, substantive saved Season intent/opening, canonical intentions created in the period, meaningful review writing or a previously captured transition. Empty seeded Season rows and elapsed quarters do not qualify. Paused time does not create activity by itself.
- Automatic arrival occurs only on a safe ordinary Home visit after successful timer reconciliation. Running **or paused** sessions, timer recovery/mutations, dirty forms, modal layers, deep links, hidden documents and begun pointer/keyboard interaction suppress it. A failed optional transition query leaves Home usable and suppresses automatic opening rather than pretending the user has no history.
- A first-time user enters the current opening directly. For prior participation, only the latest eligible past quarter is offered automatically, avoiding missed-quarter cascades. Older reviews remain manually accessible.
- Not now persists `DEFERRED`, meaning manual-only resumption indefinitely. Skip persists `SKIPPED`. Unconfirmed exits return immediately and suppress automatic re-entry in that tab while retaining recovery data.
- Numbered scene navigation persists the selected movement under the same owner lease and optimistic version. `completedMovements` is a navigation high-water marker, not evidence that intervening scenes were read. It permits direct jumps without synthetic intermediate advances. Completion still requires the currently selected closing movement and an explicit final action.
- Completion records progress once. Replays bind to the saved edition and return to its review, without reopening the current opening. An already-completed current opening returns to Home. Watching, skipping or calendar rollover never concludes a Goal/Experiment or changes a domain outcome.

## Domain facts and historical honesty

Domain-owned review providers supply the same qualifications to review aggregation, source drill-through and targeted retrieval. The review feature composes them; it does not establish a second AI truth system.

| Domain           | Qualified reading                                                                                                                                                                                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sessions         | Completed sessions clipped to each window, subtracting intersecting pauses. Cross-quarter participation uses the same SQL helper. Unfinished contribution is separately provisional, never included in completed totals. Time is not proof of attention or effort quality.                              |
| Finance          | Actual transactions by currency and inflow classification; expenses separate. No transfers, quotations, acceptance, inferred MRR or FX conversion. Scoped Work Source queries use earned-work money.                                                                                                    |
| Entrepreneurship | Current non-withdrawn interaction revisions; distinct companies deduplicated across conversations; explicit exploration judgments; non-retracted offer events; confirmed receipt allocations excluding pending review. Receipt allocations describe the same Finance money and are not additive income. |
| Content          | Creative works, variants and explicit publications counted independently. Cross-posting remains one work. Dated manual lifetime observations retain correction/release-date eligibility and are not period gains or unique people. Thumbnails are owned historical media references.                    |
| Direction        | Saved criterion definitions and lifecycle events, exact domain evaluation where reconstructable, distinct criteria-reached versus user conclusion. Conclusion events survive later reopening. Historical manual/current-state-only metrics are explicitly unavailable instead of projected backward.    |
| Ideas/Decisions  | Dated capture/promotion, explicit choices, saved reasons, changes, supersession and follow-up reflections. User judgments remain distinguishable from arithmetic facts.                                                                                                                                 |

Original Goal/Experiment wording and targets come from saved history at the period start, or the first saved definition within the period. Progress uses the last saved definition within the period and evidence available now. Later changes to a canonical start date do not erase its historical participation. Bounded change excerpts retain source links. When history cannot reconstruct intent or a dated assessment, the response says so.

Season opening wording comes from a saved opening history record, with its original recorded date. Current saved wording stays separate. Missing opening history does not turn today's intention into an asserted original. Multi-quarter reviews use a neutral period identity and distinct saved Season chapter summaries, rather than attributing a whole year to its first quarter's COTS. Open-period chapters stop at the evaluated boundary; future planned Seasons are excluded.

Recorded zero, absent coverage and failed queries are different. Coverage describes records, not undocumented real-world activity. Later corrections are evidence available now; this is not an exhaustive historical database reconstruction.

## Persistence, consistency and security

The additive `20260913010000_phase7_reviews` migration creates `Review`, append-only `ReviewEdition`, complete `ReviewEditionSource` manifests, idempotent `ReviewMutation` receipts and `SeasonTransition`. Owned composite foreign keys, unique period/edition keys, one presentation per review, and disposition/progress checks reinforce service rules. Its only legacy data transformation removes `character.tone` from active Season JSON. Historical closing snapshots and change records remain untouched; legacy tone is inert when read through the active mapper.

- Repeatable-read transactions provide coherent multi-query live packets. Serializable writes use transaction-scoped advisory locks, optimistic versions, retry on serialization conflict and operation fingerprints/receipts.
- Finalization copies evaluated facts, definitions, coverage, source revisions/excerpts, identity/media/provenance and user writing in one transaction. The complete eligible source manifest is copied in SQL; default packets do not load that entire manifest into JavaScript.
- A presentation is a frozen reading, not an explicit final review. Finalization and amendments append distinct editions. An amendment supersedes the latest final edition while preserving every earlier edition and presentation. Source corrections do not rewrite a captured finale or trigger another ceremony.
- Season finalization records closing metadata/history without replacing a legacy closing snapshot or changing canonical Goal/Experiment outcomes. Review reads reveal live/frozen differences. A failed live comparison still permits the saved edition and explicitly marks comparison unavailable.
- A 60-second renewable owner lease coordinates active finale tabs. Heartbeats do not advance optimistic versions; advance/deferral/completion do. Database serialization prevents duplicate capture and lost progress. Local tab IDs detect cloned session storage where BroadcastChannel is available and use a fresh document ID fallback.
- Reads are user-scoped, authenticated and private/no-store. Commands require same-origin requests, strict typed input and body-size limits. Related source IDs, domains, Work Sources and companies must belong to the caller. Cursor continuation binds to the content fingerprint; stale evidence returns conflict, not a misleading mixed page.
- Canonical links can open a source that has since changed; captured source explanations and retained media remain historical. No external/network work runs inside snapshot transactions.

## Versioned Phase 8 foundation

All reusable packets have schema/metric version 1, stable content fingerprints, evaluation/reference time, precise units/currency, source references, coverage, warnings and measured UTF-8 size. Fingerprints exclude volatile reference timestamps but include relevant current/prior source content, qualifications, context and selected moments. No persistent cache is introduced: no-store reads observe corrected sources immediately. Future caches can key by these content/context fingerprints.

| Packet              | Contract and limits                                                                                                                                                                                                                                                                                   |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Period review facts | `/api/reviews`; all or selected domains in the shared query; 96 KiB; 6 default weekly or 18 other moments, up to 12 explicit selections; 8 intentions and 24 criterion evaluations; complete aggregates precede bounded detail.                                                                       |
| Current context     | `/api/reviews/context`; selected domains, current Season/persona, 5 priorities, up to 4 Goals/3 Experiments, recent week facts and at most 5 sources; 32 KiB. Full text stays in canonical sources.                                                                                                   |
| Targeted retrieval  | `/api/reviews/retrieve`; discriminated `FOCUSED_TIME`, `INCOME`, `DECISIONS`, `DECISION`, `GOAL`, `EXPERIMENT`, `SOURCE`; owned scope, bounded excerpts, 10 history or 25 evidence records per page, 64 KiB. Byte-heavy evidence pages reduce page length and continue from the last returned record. |
| Evidence            | `/api/reviews/sources`; exact live fingerprint or frozen edition, total count and stable keyset pagination, at most 25 records/64 KiB.                                                                                                                                                                |
| Persona input       | 24 KiB, up to 8 approved quote references, explicit omitted count, bounded user constraints, separate identity/source/context fingerprints.                                                                                                                                                           |

Stable Season/persona context is separated from changing recent facts. Histories are fetched on demand. Default packets exclude full scripts, raw media and unrestricted notes/history. Every source-text contract treats quotes, imported text and user notes as source data rather than instructions. Payload limits measure bytes, not speculative model tokens.

### Source-grounded character profile

`personaInputSchema` carries `groundedProfile: null` in Phase 7 and reports `NO_COTS` or `AWAITING_PHASE_8_PROFILE`. The versioned future `groundedPersonaProfileSchema` explicitly supports:

- characteristic communication tendencies and temperament;
- values/priorities and ways of challenging/supporting;
- behavioral tendencies and anti-caricature boundaries;
- source references and attribution/qualification for every characteristic;
- identity/work/adaptation binding, profile ID/version and preparation time.

Profiles must reference included unique supporting sources and match the exact identity/context fingerprints. The compact researched profile has a 16 KiB bound. User admiration, rejection and practical Season standards **constrain the authentic source-grounded persona**, rather than replace it. Personality cannot change factual qualification, certainty or safety. The same future persona serves Home commentary, reviews, domains, farewell and chatbot, with context-appropriate response length. Ordinary UI/errors/financial operations remain factual.

`futureGeneratedOutputBindingSchema` reserves review-edition/context/persona fingerprints, profile ID/version, source IDs, generated time and model metadata. Attribution is explicitly `GENERATED_CHARACTER_INSPIRED_WRITING` and replay is `SAVED_OUTPUT_ONLY`. Phase 8 owns actual research, inference, AI calls, message/chat/farewell persistence and orchestration. No unused conversation tables, vectors, billing or model-tool framework were added.

- The generic COTS tone is removed from active inputs and semantics. Unrelated “Direct” Finance opportunity channels and visual error-tone properties are different concepts and remain intact.
- Phase 7 is migration-ready, not deployed. The personal database is unchanged. No commit, push, VPS access or Phase 8 work was performed.
