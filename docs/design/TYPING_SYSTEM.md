# Approved AI typing treatment

The product owner selected **Terminal Prompt** from the C.O.T.S typing comparison. Use `AiTypingText` in `src/components/ui/typing/` **solely when C.O.T.S. speaks**: character conversations, response tests and Daily Message widgets across dashboard lenses. This includes clearly labeled C.O.T.S. speech previews. The owner explicitly restricted this role on 11 October 2026. Longer AI-generated summaries, briefs and paragraphs use the separately approved `AiGeneratedText` / **Living Ink** treatment; see [AI_GENERATED_TEXT.md](AI_GENERATED_TEXT.md). Neither reveal is a generation/loading state. Do not build feature-local copies of either treatment.

The component shows the `C.O.T.S >` prompt, reveals the message character by character, and keeps a compact block caret at the writing point. The owning surface supplies its area accent through `--ai-typing-accent`; the shared fallback is the inherited text color. Visual values and cadence live in `src/app/styles/tokens.css`. Visibility threshold and other behavior counts live beside the component in `ai-typing-text.config.ts`.

The reveal starts only when the owning surface is visibly in the viewport. It pauses when scrolled out of view or when the page is hidden, then resumes without restarting. A newly mounted message may reveal again. Dashboard and domain-lens Daily Message widgets use this treatment for both clearly labeled preview copy and ready AI messages, so the approved typography and reveal remain consistent while a Season pack is still in draft. `prefers-reduced-motion: reduce` displays the entire text immediately and removes the caret animation. Screen readers receive the full message once rather than a character-by-character stream. The text and underlying application state never wait for animation to finish.

For unusually long C.O.T.S. messages, the visibility threshold applies to the area that can fit in the viewport. Target and viewport size changes refresh that threshold. General summaries no longer use Terminal Prompt.

Every C.O.T.S message uses the same approved `type-quote` typography. The widgets share a compact card height controlled by `--dashboard-cots-card-height`; on narrow screens the card may grow to keep longer messages readable. Do not scale individual messages to fill spare space. Keep the quote vertically balanced inside the card, and let unusually long copy scroll inside its quote area rather than changing its type size. The shared component reserves the completed text layout invisibly so lines do not move vertically as characters appear.
